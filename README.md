# Rok Retar — Portfolio

This repository contains my personal portfolio webpage. It is a work-in-progress and will evolve
over time as I iterate on content and design.

Live site: https://www.retar.app

## Tech stack

- Kotlin (KMP/JS) with Kobweb — Compose-like developer experience for the web
- Silk (Kobweb UI library) for styling and components
- Gradle (Kotlin DSL) for build
- GitHub Actions for export and deployment

## Status

Actively being developed. Features, layout, and content may change frequently.
